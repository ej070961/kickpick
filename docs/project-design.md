# KickPick 제품 소개서

## 1. 한 줄 소개

KickPick은 아마추어 축구팀을 위한 쿼터별 포메이션 자동 배치 서비스입니다. 선수 명단과 포지션만 준비하면 경기별 라인업을 빠르게 만들고, 현장에서 바로 수정해 이미지로 공유할 수 있습니다.

## 2. 왜 KickPick인가

아마추어 축구 경기에서는 실력만큼 운영도 중요합니다. 누가 몇 쿼터를 뛰는지, 어떤 포지션에 들어가는지, 후보는 누구인지가 명확하지 않으면 경기 전 준비 시간이 길어지고 현장 혼선도 커집니다.

KickPick은 이런 반복적인 배치 작업을 줄여줍니다. 팀의 선수 정보, 주 포지션, 부 포지션, 우선순위, 경기 조건을 바탕으로 쿼터별 포메이션 초안을 자동으로 만들고, 사용자는 축구장 화면에서 필요한 부분만 직관적으로 조정하면 됩니다.

## 3. 핵심 가치

- 빠른 경기 준비: 참가 선수와 경기 조건을 입력하면 쿼터별 배치 초안을 자동 생성합니다.
- 공정한 출전 관리: 선수별 출전 쿼터 수를 최대한 균등하게 배분합니다.
- 포지션 기반 배치: 주 포지션, 부 포지션, 포지션 그룹을 고려해 자연스러운 라인업을 제안합니다.
- 현장 대응력: 부상, 지각, 이탈, 전술 변경이 생겨도 경기 상세 화면에서 바로 수정할 수 있습니다.
- 쉬운 공유: 완성된 쿼터별 포메이션을 PNG 이미지로 저장해 카카오톡 등 외부 채널에 공유할 수 있습니다.

## 4. 주요 사용자

- 경기 전 라인업과 쿼터별 출전 계획을 준비하는 팀 관리자
- 경기 중 선수 교체와 포지션 변경을 빠르게 반영해야 하는 운영자
- 경기 배치표를 팀원에게 이미지로 공유하고 싶은 아마추어 축구팀

## 5. 사용 흐름

### 5.1 선수 명단 준비

팀 선수의 이름, 등번호, 주 포지션, 부 포지션을 등록합니다. 선수별 우선순위도 관리할 수 있어, 자동 배치 시 팀 운영 기준을 함께 반영할 수 있습니다.

### 5.2 포메이션 템플릿 생성

팀에서 자주 쓰는 포메이션을 템플릿으로 저장합니다. GK를 포함한 11개 슬롯으로 구성되며, 저장된 템플릿은 경기 생성 시 바로 선택할 수 있습니다.

### 5.3 경기 만들기

경기명, 날짜, 쿼터 수, 포메이션, GK 고정 여부를 입력합니다. 참가할 팀 선수를 선택하고, 그날만 함께 뛰는 용병도 별도로 추가할 수 있습니다.

### 5.4 쿼터별 자동 배치

KickPick은 참가 인원과 쿼터 수를 기준으로 선수별 목표 출전 수를 계산합니다. 이후 각 선수의 포지션 적합도와 우선순위를 반영해 쿼터별 포메이션 초안을 생성합니다.

### 5.5 포메이션 검토와 수정

생성된 배치는 축구장 화면에서 바로 확인할 수 있습니다. 슬롯을 선택해 선수끼리 교체하거나, 현재 쿼터에 뛰지 않는 후보 선수와 바꿀 수 있습니다.

### 5.6 저장과 공유

수정한 포메이션은 저장할 수 있고, 현재 쿼터 배치표는 PNG 이미지로 내보낼 수 있습니다. 이미지에는 쿼터 라벨이 포함되어 팀원들이 각 쿼터 배치를 쉽게 확인할 수 있습니다.

## 6. 현재 제공 기능

### 6.1 팀 계정과 로그인

KickPick은 팀 단위로 데이터를 관리합니다. Kakao와 Google 로그인을 제공하고, 계정 연결 전에 바로 경험해볼 수 있는 체험 모드를 지원합니다. 로그인한 사용자와 체험 사용자 모두 각자의 팀 공간 안에서 선수, 포메이션, 경기 데이터를 관리합니다.

### 6.2 선수 관리

선수 명단을 등록하고 계속 관리할 수 있습니다.

- 선수 생성, 수정, 삭제
- 이름과 등번호 관리
- 주 포지션과 부 포지션 설정
- 선수 우선순위 저장
- 드래그 앤 드롭 기반 우선순위 변경

### 6.3 포메이션 템플릿 관리

팀이 사용하는 포메이션을 직접 만들어 저장할 수 있습니다.

- 팀별 포메이션 템플릿 생성
- GK 포함 11개 슬롯 구성
- 필드 슬롯 10개 선택 후 GK 자동 포함
- 생성된 템플릿 목록 확인
- 사용하지 않는 템플릿 삭제

### 6.4 경기 생성

경기 운영에 필요한 조건을 한 번에 입력해 자동 배치 초안을 만듭니다.

- 경기명과 경기 날짜 입력
- 쿼터 수 선택
- 포메이션 템플릿 선택
- GK 전 쿼터 고정 여부 선택
- 참가 선수 선택
- 경기 전용 용병 추가, 수정, 삭제
- 적은 쿼터 또는 많은 쿼터 배정 대상 선택

### 6.5 쿼터별 자동 포메이션

자동 배치는 단순 랜덤 배정이 아니라 팀 운영에 필요한 기준을 반영합니다.

- 선수별 목표 출전 쿼터 수 계산
- 주 포지션 일치 우선
- 부 포지션 일치 반영
- 같은 포지션 그룹 대체 가능성 반영
- 선수 우선순위 반영
- 한 쿼터 안 동일 선수 중복 배정 방지
- GK 고정 시 GK 슬롯 별도 처리

### 6.6 포메이션 편집기

경기 상세 화면에서는 쿼터별 배치를 실제 경기장처럼 확인하고 수정할 수 있습니다.

- 쿼터 탭 전환
- 축구장 이미지 위 선수 배치 확인
- 슬롯 간 선수 교체
- 후보 선수와 출전 선수 교체
- 선수별 전체 출전 쿼터 수 요약
- 변경사항 저장
- 현재 쿼터 PNG 저장

### 6.7 경기 중 명단 수정

경기 당일 예상과 다른 상황이 생겨도 상세 화면에서 바로 반영할 수 있습니다.

- 팀 선수 추가
- 참가자 제거
- 경기 전용 용병 추가
- 용병 정보 수정
- 용병 삭제
- 참가자 제거 시 해당 선수의 모든 배정 슬롯 비우기

### 6.8 포메이션 변경과 재배정

경기 도중 전술을 바꿔야 할 때도 기존 경기 데이터를 유지하면서 포메이션을 변경할 수 있습니다.

- 등록된 포메이션 템플릿으로 경기 포메이션 변경
- 전체 재배정
- 쿼터별 출전 선수 유지 재배정
- 변경 전 영향 범위 안내

## 7. 준비 중인 기능

아래 기능은 경기 생성 이후의 편집 편의성과 공유 속도를 높이기 위해 추가 예정입니다.

### 7.1 생성된 경기 이름 바꾸기

경기를 만든 뒤에도 경기 이름을 수정할 수 있게 됩니다. 상대 팀명, 날짜, 대회명 등을 나중에 정리해도 경기 목록과 상세 화면, 이미지 파일명에 자연스럽게 반영됩니다.

예상 사용 방식:

- 경기 상세 화면에서 경기명 옆 편집 버튼 클릭
- 새 경기명 입력
- 저장 후 화면 제목과 이미지 저장 파일명에 즉시 반영

### 7.2 모든 쿼터 사진 일괄 저장

현재는 보고 있는 쿼터만 PNG로 저장할 수 있지만, 앞으로는 모든 쿼터 배치표를 한 번에 저장할 수 있게 됩니다.

예상 사용 방식:

- 포메이션 편집기에서 `전체 쿼터 저장` 선택
- 1Q부터 마지막 쿼터까지 순서대로 이미지 생성
- 쿼터별 PNG 파일을 한 번에 다운로드
- 필요 시 ZIP 파일로 묶어 저장

이 기능은 경기 전 팀원 공유나 경기 후 기록 보관에 특히 유용합니다.

### 7.3 쿼터 순서 바꾸기

생성된 쿼터의 순서를 나중에 바꿀 수 있게 됩니다. 예를 들어 3쿼터와 4쿼터를 통째로 바꾸면, 해당 쿼터에 배정된 선수와 포지션 전체가 함께 이동합니다.

예상 사용 방식:

- 쿼터 순서 변경 화면 열기
- 쿼터 카드를 드래그하거나 위/아래 버튼으로 이동
- 변경된 순서 확인
- 저장 후 쿼터 탭, 화면 라벨, 이미지 파일명에 새 순서 반영

## 8. 화면 구성

### 8.1 대시보드

경기 만들기, 선수 관리, 포메이션 관리로 빠르게 이동할 수 있는 시작 화면입니다.

### 8.2 선수 관리

팀 선수 명단을 관리하는 화면입니다. 선수별 포지션과 우선순위를 정리해 자동 배치 품질을 높일 수 있습니다.

### 8.3 우선순위 관리

선수 우선순위를 드래그 앤 드롭으로 조정하는 화면입니다. 팀 운영 기준에 따라 자동 배치 우선순위를 관리할 수 있습니다.

### 8.4 포메이션 관리

팀에서 사용하는 포메이션 템플릿을 만드는 화면입니다. 경기 생성 시 저장된 템플릿을 선택해 빠르게 배치를 시작할 수 있습니다.

### 8.5 경기 목록

생성한 경기들을 모아보는 화면입니다. 경기명, 날짜, 쿼터 수, 포메이션을 확인하고 상세 편집 화면으로 이동할 수 있습니다.

### 8.6 경기 생성

경기 조건과 참가자를 입력하고 자동 배치 초안을 만드는 화면입니다. 등록 선수와 경기 전용 용병을 함께 선택할 수 있습니다.

### 8.7 포메이션 편집기

KickPick의 핵심 작업 화면입니다. 쿼터별 포메이션을 축구장 이미지 위에서 확인하고, 선수 교체, 명단 수정, 포메이션 변경, 저장, 이미지 내보내기를 한 흐름으로 처리합니다.

## 9. 디자인 방향

KickPick은 밝고 명확한 스포츠 운영 도구를 지향합니다. 화려한 장식보다 경기 준비와 현장 수정에 필요한 정보를 빠르게 확인할 수 있는 화면을 우선합니다.

- 주요 액션은 명확하게 드러냅니다.
- 모바일에서도 버튼과 슬롯을 쉽게 누를 수 있게 합니다.
- 선수, 포지션, 쿼터 정보를 한눈에 구분할 수 있게 합니다.
- 상태 변화는 색상뿐 아니라 텍스트와 아이콘으로도 전달합니다.
- 경기 중 사용할 수 있도록 화면 흐름을 단순하게 유지합니다.

## 10. 모바일 사용성

KickPick은 경기 전 현장에서 휴대폰으로 사용하는 상황을 중요하게 봅니다.

- 주요 버튼과 선수 슬롯은 충분한 터치 영역을 제공합니다.
- 입력 폼은 모바일에서 한 줄에 하나씩 배치합니다.
- 쿼터 전환, 후보 확인, 선수 교체, 저장을 같은 흐름 안에서 처리합니다.
- 긴 선수 목록은 검색, 정렬, 접힘 구조로 다루기 쉽게 만듭니다.
- 전체 쿼터 저장과 쿼터 순서 변경 같은 추가 기능도 모바일 조작을 기준으로 설계합니다.

## 11. 공유와 활용 시나리오

### 11.1 경기 전 공유

감독이나 운영자가 KickPick으로 쿼터별 배치표를 만든 뒤 팀 채팅방에 이미지로 공유합니다. 팀원들은 본인이 몇 쿼터에 어떤 포지션으로 뛰는지 미리 확인할 수 있습니다.

### 11.2 경기 중 수정

지각, 부상, 체력 저하, 전술 변경이 생기면 상세 편집기에서 바로 선수를 교체하거나 포메이션을 바꿉니다. 수정된 쿼터 이미지를 다시 저장해 팀원에게 공유할 수 있습니다.

### 11.3 경기 후 기록

경기별 배치표를 이미지로 보관해 실제 운영 기록으로 활용할 수 있습니다. 추후 전체 쿼터 일괄 저장 기능이 추가되면 경기별 포메이션 기록을 더 쉽게 남길 수 있습니다.

## 12. 내부 구현 참고

이 섹션은 제품 소개 문서의 부록이며, 실제 개발 시 확인해야 하는 기준을 요약합니다.

### 12.1 데이터 모델 요약

상세 스키마는 `docs/database-schema.md`를 기준으로 합니다.

- `teams`: 로그인 사용자가 소유하는 팀 workspace
- `players`: 팀 선수 명단, 등번호, 포지션, 우선순위
- `formation_templates`: 팀별 포메이션 템플릿
- `formation_template_slots`: 템플릿의 11개 슬롯과 좌표
- `matches`: 경기명, 날짜, 쿼터 수, GK 고정 여부, 포메이션명, 상태
- `match_players`: 경기 참가 선수와 목표 쿼터 수
- `match_guest_players`: 해당 경기에서만 사용하는 용병 snapshot
- `quarter_formations`: 경기별 쿼터와 쿼터 번호
- `formation_slots`: 쿼터별 슬롯 배정, 좌표, 선수, 적합도, 수동 변경 여부

현재 앱은 팀 전환 UI가 없으므로 사용자의 첫 번째 팀을 현재 팀으로 사용합니다. 추후 여러 팀 관리 기능을 추가할 때는 current team 선택 정책을 별도로 확장합니다.

### 12.2 추가 예정 기능의 데이터 영향

- 경기명 수정은 `matches.name` 업데이트로 처리합니다.
- 전체 쿼터 이미지 저장은 DB 스키마 변경 없이 클라이언트 export 로직 확장으로 처리할 수 있습니다.
- 쿼터 순서 변경은 `quarter_formations.quarter_number` 업데이트가 필요하며, unique 제약 충돌을 피하는 저장 전략이 필요합니다.

### 12.3 기술 스택

- Framework: Next.js App Router
- UI: React, TypeScript, Tailwind CSS
- Backend/Auth/DB: Supabase
- Form/action validation: Server Actions, `useActionState`, `zod`
